Windows 연동 테스트 · 0.2.0

Tab Audio Router

Chrome 탭의 소리를 Windows에서 선택한 이어폰이나 스피커로 보냅니다.

Windows 보조 프로그램 다운로드

설치 및 연결

  1. ZIP을 풀고 해당 폴더를 보관합니다. 설치 후 폴더 경로가 유지되어야 합니다.
  2. Windows 연동을 지원하는 Tab Audio Router 확장의 ID를 복사합니다. ZIP을 풀어 둔 폴더에서 PowerShell을 열고, 아래 명령의 복사한확장ID를 바꿔 실행합니다. 
    .\Register.ps1 -ExtensionId "복사한확장ID"
  3. 음악 탭에서 확장 아이콘을 열어 제어 시작을 누르고, Windows가 붙은 출력 장치를 선택합니다.

Windows 장치 목록 조회를 확인했습니다. Chrome 탭의 실제 재생과 두 장치 동시 출력은 테스트가 필요합니다.

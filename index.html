Tab Audio Router

Windows 설치 앱 다운로드

설치 방법

  1. 다운로드한 설치 앱을 엽니다.
  2. Chrome의 chrome://extensions에서 Windows 연동을 지원하는 Tab Audio Router 확장의 ID를 복사합니다.
  3. 설치 앱에 ID를 붙여넣고 설치를 누릅니다.
  4. Chrome에서 확장 팝업을 다시 열어 Windows 출력 장치를 선택합니다.

탭 오디오를 보내려면 Windows 연동을 지원하는 확장이 별도로 필요합니다. Chrome 탭의 실제 재생과 두 장치 동시 출력은 테스트가 필요합니다.

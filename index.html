Windows 연동 테스트 · 0.2.0

Tab Audio Router

Chrome 탭의 소리를 Windows에서 선택한 이어폰이나 스피커로 보냅니다.

Windows 테스트 ZIP 다운로드

설치 및 연결

  1. ZIP을 풀고 해당 폴더를 보관합니다. 설치 후 폴더 경로가 유지되어야 합니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다. 기존 Tab Audio Router를 잠시 끄고, 개발자 모드에서 압축해제된 확장 프로그램을 로드합니다를 눌러 ZIP 안의 extension 폴더를 선택합니다.
  3. 새 확장 카드의 ID를 복사합니다. ZIP을 풀어 둔 폴더에서 PowerShell을 열고, 아래 명령의 복사한확장ID를 바꿔 실행합니다. 
    .\Register.ps1 -ExtensionId "복사한확장ID"
  4. 음악 탭에서 확장 아이콘을 열어 제어 시작을 누르고, Windows가 붙은 출력 장치를 선택합니다.

Windows 장치 목록 조회를 확인했습니다. Chrome 탭의 실제 재생과 두 장치 동시 출력은 테스트가 필요합니다.
